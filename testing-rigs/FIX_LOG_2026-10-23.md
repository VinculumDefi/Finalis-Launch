## Fail-closed choices (spec silent)

1. AG-04: one RAC per proven lock (environment plus lock id), whatever racIdentity the package states. A second RAC is refused, not merged.
2. AG-05: the Valuation Timestamp must equal the proven creation time exactly; no tolerance window. A creation time later than the current block is refused.
3. AG-06: the price used is the run in effect strictly before creation (a run in the same second as creation does not count). No run, or a failed run, in effect at creation refuses the lock permanently and records no RAC; a later successful run does not cure it (VF-ORC-005, VF-FEE-011). The fee already taken by the lock is not refunded by the Verifier.
4. AG-06 / COMB-03: a USDC/USDT row priced below $0.95 at creation is refused permanently (fee taken, no mint), even after the peg recovers. Residual: the app should block such locks before they are made.
5. AG-07: run ids must be exactly the next id; there is no gap tolerance and no upper bound other than the sequence. A reverted run does not consume an id. Prices above uint128 max are refused.
6. AG-09: a reader that cannot report the Dev Fund (no lockDevFund) is refused, as is any Dev Fund other than the configured one.
7. AG-01, AG-02, AG-03: every non-Base reader refuses finality until an anchored finality proof exists, so non-Base environments are disabled rather than trusted. An empty block is refused.
8. AG-08: fee-on-transfer tokens are refused at lock time; a negative rebase blocks new locks and releases pay a pro-rata share; a positive rebase pays exactly the principal and leaves the surplus in the contract. The Dev Fund must receive at least fee - 2 wei (rounding allowance for rebasing share math), and never more than the fee leaves the contract.
9. FZ-04: gross above max/1e18 is refused with VF-COM-011 instead of reverting by panic.
10. FZ-06, FZ-07: malformed RLP and oversized input counts are refused with VF-XCH-011 coded errors before any allocation.
11. HH-008: the app always sends approve(0) first when the current allowance is nonzero.
