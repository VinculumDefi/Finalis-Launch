Base ceremony

Deploys a new CommitmentVaultLock("Base"), VCLM, CHONX, and VinculumFinalisVerifier, and a Base reader bound to the new lock. It does not use the old Base lock or verifier. Every lock duration, including the 1-hour Handshake, charges 5.00% of gross. The Handshake must be $0.01 to $0.02; every other duration must be at least $0.01.

Order, as the Verifier enforces it: register the Base reader; write the registry in batches of 50, including the Base native-ETH key (registry row 2); set the Dev Fund; set the price poster (this wallet); write the scheduled Base ETH price; read it back as usable; then finalize. finalize() reverts unless all of these are in place. The Dev Fund, registry, and price come from ceremony-data.json, written by build_ceremony_artifacts.cjs. If the price is missing, the page sends nothing.
